description Mission Objective

Built as a full-stack, AI-powered system, Taskly leverages Spec-Driven Development with Claude Code to ensure architectural integrity. It is a cloud-native solution designed for high-availability and scalable performance.

The integrated chatbot, powered by the OpenAI Agent SDK and enhanced with MCP Servers, understands natural language to perform complex task operations (add, delete, update, edit) via simple prompts. The entire ecosystem is containerized and deployed using Kubernetes (Minikube + Helm Charts).
